# 论文（LW）材料

## 题目
Spring Boot 校园绿色快递驿站小程序的设计与实现

## 摘要
本文设计并实现了一套面向高校场景的绿色快递驿站系统。系统采用 Spring Boot 构建服务端，使用 JPA 完成对象关系映射，MySQL 存储业务数据，微信原生小程序提供移动端服务。系统支持用户登录、快递查询、取件确认和公告展示等功能，能够减少传统取件流程中的信息不对称，并通过绿色寄递倡议提升校园环保意识。

## 关键词
Spring Boot；微信小程序；JPA；MySQL；绿色物流

## 目录建议
1. 绪论：研究背景、意义、国内外现状
2. 需求分析：用户、快递员、管理员角色及功能需求
3. 系统设计：总体架构、数据库设计、接口设计
4. 系统实现：登录、快递入库、取件确认、公告模块
5. 系统测试：功能测试、接口测试、兼容性测试
6. 总结与展望

## 测试用例示例
- 使用 demo/123456 登录，验证返回 JWT。
- 登录后访问快递列表，验证仅返回当前用户数据。
- 对待取件快递执行取件，验证状态变为 PICKED_UP。
- 未登录访问业务接口，验证客户端被要求登录。
